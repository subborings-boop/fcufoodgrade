# 產品需求文件 (PRD) - 逢甲美食評論網

## 1. 專案概述

### 背景與動機
逢甲商圈（逢甲夜市）是全台知名的觀光與美食重鎮，然而網路上（如 Google Maps、部落格、IG）的評價多被觀光客導向的偏好、一次性消費體驗或商家的行銷業配所盤據。對於每日在校園周邊活動的逢甲大學學生而言，這些評價往往無法切中其真實痛點。
學生更在乎的是：
*   **高性價比 (CP值)**：平價、份量大、加麵/加飯不用錢。
*   **空間與氛圍**：是否有插座、不限時、適合久坐讀書或討論報告。
*   **社交與聚會**：空間是否夠大、是否適合舉辦系聚或社團聚餐。

本專案旨在建立一個「專屬於逢甲大學師生」的美食評價平台。透過校園 Email 帳號驗證，過濾觀光客及無效業配的雜音，讓真實的校園心得得以分享，打造出最貼近逢甲人日常飲食需求的「在地飲食指南」。

### 目標用戶
*   **逢甲大學學生**：尋求平價、大份量、且適合久坐、討論報告或系聚聚餐的餐廳資訊。
*   **剛入學的新生**：缺乏對校園周邊地理位置（如正門、東門、西門、文華路）與飲食地標的認知，需要快速融入校園生活。
*   **校園周邊商家**：希望了解逢甲學生的真實回饋，藉以提升服務品質、調整菜單，並在校內建立良好口碑以吸引穩定客源。

### 核心價值主張
*   **學生認證，真實可靠**：僅限逢甲大學信箱註冊驗證，排除觀光客與洗評價行為。
*   **痛點標籤，快速篩選**：獨家提供「平價/大份量/適合久坐/適合系聚/提供插座」等多維度學生專屬標籤檢索。
*   **校園定位，鄰近尋找**：結合逢甲校園地標（如：積學堂、商學大樓、東門、西門），方便學生下課後快速步行抵達。

## 2. 功能需求

本平台規劃五大核心功能模組，以下詳細說明功能細節與對應的使用者故事：

### 功能一：校園信箱註冊與驗證系統
*   **說明**：使用者必須使用逢甲大學官方信箱（例如 `@fcu.edu.tw` 或 `@mail.fcu.edu.tw`）進行註冊，並完成信箱驗證（MVP 階段可先以模擬驗證信或格式檢查代替，後續再串接 SMTP），以確保用戶身分的真實性。
*   **使用者故事**：
    *   *作為* 逢甲大學學生，*我希望* 能使用學校信箱快速註冊與登入，*以便* 我能在平台上發表評論並查看其他同學的真實分享。
    *   *作為* 系統管理員，*我希望* 系統能自動驗證註冊信箱的後綴域名，*以便* 過濾校外人士、觀光客或水軍的惡意註冊，維護平台評論的純淨度。

### 功能二：餐廳瀏覽與多維度標籤檢索
*   **說明**：提供餐廳列表與詳細資訊頁面。除了一般關鍵字搜尋，還支援依據校區地理位置（如：正門、便當街、西安街、東門）以及學生痛點標籤（如：平價、大份量、有插座、適合系聚）進行複合式篩選。
*   **使用者故事**：
    *   *作為* 逢甲大學學生，*我希望* 能勾選「有插座」和「適合久坐」標籤，*以便* 找到適合下午邊吃點心邊用電腦寫程式的咖啡廳。
    *   *作為* 剛入學的新生，*我希望* 能依據「校園位置：東門」進行搜尋，*以便* 下課後能以最快速度走到附近的便當店用餐。

### 功能三：互動式美食評論與評分系統
*   **說明**：已登入的認證學生可以針對餐廳撰寫食記與評論。評分維度除綜合星等外，還細分為「美味度」與「CP值」；學生亦能對他人的評論進行按讚（覺得有用）或留言討論。
*   **使用者故事**：
    *   *作為* 逢甲大學學生，*我希望* 在吃完一頓很划算的午餐後，能上傳食物照片並給予該店 CP 值 5 顆星，*以便* 推薦給其他預算有限的同學。
    *   *作為* 逢甲大學學生，*我希望* 能對寫得很詳細的食記按下「這篇評論對我有幫助」，*以便* 讓優質的真實心得能排在前面，不被敷衍的字句掩蓋。

### 功能四：個人口袋名單與收藏管理
*   **說明**：提供「收藏餐廳」功能，使用者可點擊餐廳旁的愛心將其存入個人名單。進階版可自訂名單名稱（如：「歐趴糖首選」、「期末聚餐清單」），方便分類管理。
*   **使用者故事**：
    *   *作為* 逢甲大學學生，*我希望* 將常去的宵夜攤位加入「我的收藏」，*以便* 在深夜飢餓時能迅速查閱其營業時間與地址。
    *   *作為* 班級幹部（活動股長），*我希望* 能建立一個「系聚候選餐廳」的自訂名單，*以便* 在期末籌備班級聚餐時，方便與同儕分享討論。

### 功能五：商家特約優惠與回饋機制
*   **說明**：預留商家認證機制，使商圈合作特約店家能刊登專屬逢甲學生的優惠資訊（如「出示此頁面送小菜」或「憑學生證打九折」）。同時，店家可對學生的評論進行官方客氣回應，達成雙向溝通。
*   **使用者故事**：
    *   *作為* 校園周邊商家，*我希望* 能在平台上發布「憑逢甲學生證消費滿百送飲料」的特約優惠，*以便* 在開學季吸引新生光顧。
    *   *作為* 校園周邊商家，*我希望* 針對學生提出的環境整潔或服務態度負評進行說明與改善承諾，*以便* 重塑店家形象並提升校內口碑。

## 3. 非功能需求

### 技術限制
*   **後端框架**：使用 Python 的 **Flask** 框架作為主要 Web 應用服務核心。
*   **前端技術**：採用 **Jinja2 模板引擎** 進行頁面動態渲染，並搭配 **Vanilla CSS** 來開發高質感、具現代美學（如 HSL 漸層、Glassmorphism 玻璃擬態、平滑轉場微動畫）的響應式網頁（RWD），不使用繁瑣的 TailwindCSS 以確保設計細節的精準控管。
*   **資料庫**：使用 **SQLite** 進行本地端資料儲存，便於部署與快速原型驗證。

### 效能考量
*   **回應時間**：首頁、餐廳列表及關鍵字搜尋等高頻網頁，伺服器渲染與載入時間應在 1.5 秒以內（在正常網路環境下）。
*   **查詢優化**：在 SQLite 資料庫中，應針對餐廳的 `name`、`landmark`（校區位置）及熱門 `tag` 建立索引（Index），以防隨資料量增加而導致查詢變慢。
*   **靜態資源快取**：妥善設定 CSS、JS 及圖片等靜態檔案之快取機制，降低伺服器頻寬負擔。

### 安全考量
*   **密碼儲存安全**：所有使用者密碼在儲存至 SQLite 之前，必須使用 `werkzeug.security` 的 `generate_password_hash` 進行單向雜湊加密，絕對不以明文儲存。
*   **防範 SQL 注入 (SQL Injection)**：一律使用 Flask-SQLAlchemy ORM 的參數化查詢，不使用字串拼接方式執行 SQL 指令。
*   **防範跨站腳本攻擊 (XSS)**：利用 Jinja2 的自動轉義（Auto-escaping）機制，對所有使用者輸入的評論內容、留言進行 HTML 轉義，防止惡意腳本注入。
*   **身分驗證與授權**：限制發布評論、新增收藏、管理口袋名單等敏感操作之路由，必須驗證 Session 中存有登入 Token，防止未授權的偽造操作。

## 4. MVP 範圍 (Minimum Viable Product)

為了確保專案能穩健且快速地推出第一版進行驗證，我們將需求劃分為以下三個層級：

| 優先權等級 | 功能項目 | 具體範圍與規格 |
| :--- | :--- | :--- |
| **Must Have (核心必備)** | 1. 逢甲信箱註冊登入 | - 支援 `@fcu.edu.tw` 與 `@mail.fcu.edu.tw` 格式檢查。<br>- 使用者密碼 Hash 加密儲存。 |
| | 2. 餐廳基本檢索 | - 支援關鍵字搜尋餐廳名稱。<br>- 支援依「正門/東門/西門」等區域進行初步分類。 |
| | 3. 餐廳詳細頁面與評分 | - 呈現餐廳地址、營業時間、照片。<br>- 可對餐廳進行總體星等、美味度、CP 值的評分與文字評論。 |
| | 4. 個人收藏名單 | - 登入狀態下，可點擊愛心收藏餐廳。<br>- 設有個人專區檢視所有已收藏之餐廳。 |
| **Should Have (應該擁有)** | 1. 痛點標籤篩選 | - 支援「大份量」、「適合久坐」、「有插座」、「平價」等多選標籤篩選。 |
| | 2. 評論互動系統 | - 學生可對其他人的評論按下「這篇有幫助」（按讚）。<br>- 支援在他人評論下方進行二級留言回覆。 |
| | 3. 口袋名單分類 | - 允許使用者建立自訂名稱的名單，並將餐廳分類歸檔（如：宵夜、系聚）。 |
| **Nice to Have (未來擴充)** | 1. 商家特約與回饋 | - 提供商家帳號註冊，並能於前台標示「逢甲特約特約商家」與登載優惠券。<br>- 商家可對學生評論進行官方回覆。 |
| | 2. 地圖定位與導航 | - 結合 Leaflet 或 Google Maps，在地圖上標記餐廳與校門的相對位置。 |
| | 3. 逢甲美食排行榜 | - 每週/每月自動根據評分與點閱率，生成「逢甲 CP 值霸主」、「熱門讀書咖啡廳」等動態排行榜。 |
